## 1. 기능적 요구사항 (Functional Requirements)

작성하신 코드의 로직이 구현하는 '동작'들입니다.

* **R1. 홈 화면 제공**: 사용자가 접속했을 때 서비스의 목적과 환영 메시지를 보여주어야 한다. (`/`, `/home`)
* **R2. 프로젝트 목록 조회**: 개발자가 수행한 프로젝트 리스트(Flask, ML 등)를 사용자에게 노출해야 한다. (`/projects`)
* **R3. 연락처 정보 제공**: 협업을 위해 개발자의 이메일 등 연락처 정보를 확인할 수 있어야 한다. (`/contact`)

---

## 2. 비기능적 요구사항 (Non-functional Requirements)

코드에는 직접 안 나타나지만, 서비스의 **'품질'**을 결정하는 요소들입니다.

* **성능(Performance)**: 사용자가 각 페이지를 요청했을 때 응답 시간이 1초 이내여야 한다.
* **가용성(Availability)**: 파이썬 Flask 서버가 구동되는 동안 중단 없이 서비스가 제공되어야 한다.
* **코드 품질**: 향후 유지보수를 위해 변수명과 함수명을 명확히 정의하고 PEP8 표준을 준수한다.
* **확장성(Scalability)**: 추후 데이터베이스(SQLite 등)를 연결하기 용이하도록 라우트 구조를 설계한다.
